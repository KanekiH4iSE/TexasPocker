# Покер онлайн

Техасский холдем (No-Limit) для друзей: без регистрации, на условные фишки.
Создаёшь стол, отправляешь ссылку или 4-буквенный код, играете в браузере с телефона или компьютера.

## Запуск

```bash
npm install
npm start          # http://localhost:3000
npm test           # оценка комбинаций + симуляция сотен раздач
```

Переменная `PORT` задаёт порт (на Render выставляется сама).

## Как играть

1. Первый игрок вводит имя и жмёт «Создать стол», затем «Пригласить» (копирует ссылку `/?room=КОД`).
2. Остальные открывают ссылку, вводят имя и садятся (до 8 человек, можно подсаживаться в ходе игры: они играют со следующей раздачи).
3. Хозяин стола жмёт «Начать игру». Дальше раздачи идут сами.
4. Каждому 1000 фишек, блайнды 10/20. Кто остался без фишек, может «Докупить».
5. На ход 30 секунд. Не успел: авто-чек или авто-фолд. Если игрок отключился, ждём 8 секунд.
6. Обновили страницу или пропал интернет: вы возвращаетесь на своё место автоматически (токен хранится в браузере).

## Правила, которые реализованы

- Блайнды, кнопка дилера, хедз-ап (дилер = малый блайнд), минимальный рейз, олл-ин.
- Побочные банки при олл-инах разного размера, деление банка при равных комбинациях.
- Все в олл-ине: оставшиеся карты открываются по очереди.
- Чужие карты не уходят на клиент, пока не вскрытие.

## Устройство

| Файл | Что делает |
| --- | --- |
| `lib/hand.js` | оценка комбинаций из 5–7 карт |
| `lib/table.js` | движок стола: раздача, торговля, банки, таймеры |
| `server.js` | HTTP (статика) и WebSocket, комнаты в памяти |
| `public/` | клиент: HTML, CSS, JS без сборки |
| `test/poker.test.js` | тесты комбинаций и симуляция раздач (фишки не пропадают) |

Сеть: клиент шлёт `create`, `join`, `start`, `act`, `rebuy`, `leave`; сервер отвечает
`joined`, `state` (своё представление стола для каждого игрока), `error`, `left`.
Карты оппонентов в `state` приходят как `??`.

## Деплой на Render (бесплатно)

New → Blueprint → выбрать репозиторий. `render.yaml` уже настроен
(`runtime: node`, `plan: free`, healthcheck `/healthz`).

Бесплатный тариф засыпает через ~15 минут без запросов (первое открытие после сна
около минуты) и не хранит данные: комнаты живут в памяти, после перезапуска или
деплоя столы пропадают. Для игры с друзьями этого достаточно.

## Ограничения

- Игра на условные фишки, платежей нет.
- Нет защиты от сговора игроков: это игра для знакомых.
- Одно соединение на игрока: открыть тот же стол в двух вкладках нельзя, старая вкладка отключится.
